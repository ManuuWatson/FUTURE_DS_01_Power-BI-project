# FUTURE_DS_01  
**E-commerce Business Sales Dashboard — Power BI**

---

## 🧭 Overview  
This repository contains the Power BI project and deliverables for the **"Business Sales Dashboard from E-commerce Data"** task.  

The dashboard helps business owners and decision-makers answer key questions:
- 🏆 What are the best-selling products?  
- 📅 When do sales peak during the year?  
- 💰 Which categories or regions bring the most revenue?

## 🚀 How to Open  
1. Install **Power BI Desktop** (if not installed).  
2. Open `Dashboard/Ecommerce_Dashboard.pbix` in Power BI Desktop.  
3. Use the **slicers** (Category, Region, Year) to explore interactive visuals.
